# 光影迷宮（Raycasting 3D 迷宮）

單檔 HTML5 的第一人稱 3D 迷宮遊戲，使用偽 3D Raycasting 引擎渲染，無任何外部依賴，開啟瀏覽器即可遊玩。支援桌面（鍵盤滑鼠）與移動端（觸控搖桿）。

- 版本：v2.3
- 語言：繁體中文（zh-TW）
- 檔案：`raycast-maze.html`（單檔，約 10,300 行）

## 快速開始

直接用瀏覽器開啟 `raycast-maze.html` 即可，不需安裝或連網。

```
raycast-maze.html
```

或在本機啟動簡單伺服器後瀏覽（非必要，純本機檔案也可直接開啟）：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000/raycast-maze.html
```

## 遊戲內容

從綠色起點出發，避開陷阱與敵人，收集寶石與道具，找到金色終點即可通關。

### 核心系統

- **偽 3D 渲染**：自製 Raycasting 引擎、紋理貼圖、動態光照、手電筒、霧、晝夜循環、天氣（雨／暴風／霧／雪／沙塵暴）
- **多尺寸迷宮**：13 檔隨機迷宮（迷你 5×5 ～ 無邊 89×89），遞迴回溯演算法生成，每局不同
- **難度**：普通／困難／噩夢（噩夢無小地圖、視野更短）
- **敵人**：巡邏者、追獵者、遠程射手、裝甲坦克、群聚 swarm、炸彈兵（自爆）、旋轉哨兵（光束）、分裂體、四階段 Boss（含狂暴）
- **戰鬥**：近戰武器連擊、衝刺、能量彈、升級／經驗值／連擊倍率
- **道具**：補血、加速、護盾、無敵、能量水晶、經驗石、體魄（提升最大生命）
- **機關**：尖刺陷阱、鎖門（需鑰匙）、成對傳送點、寶石檢查點
- **學習模式**：通關後與 A* 最短路徑對比，顯示繞路格數與效率
- **上帝視角（v2.2）**：按 `G`（或觸控「神」按鈕）切換 2D 俯視全圖——牆、門、尖刺、寶石、鑰匙、傳送點、終點、敵人、玩家朝向與自動遊玩規劃路徑一目了然，遊戲照常運行

### 自動遊玩與演算法

- 一鍵自動尋路通關，支援 **A\*／BFS／貪婪** 三種演算法切換
- 路徑對比模式：同時顯示三種演算法的路徑與距離
- 幽靈模式：顯示最短路徑的教學幽靈
- **AI 戰鬥（v2.2）**：自動遊玩遇到敵人會主動面向攻擊，敵人貼近時側向閃避／後退風箏，不再被動挨打或卡住
- **路線優化（v2.2）**：目標選擇會評估「到寶石 + 寶石到終點」的整體路徑長度，選總路線最短的寶石，避免先拿近但繞遠的寶石
- 修復（v2.2）：地圖尺寸與敵人數量可同時選擇，不再互相覆寫
- **戰鬥強化（v2.3）**：自動遊玩戰鬥加入視線檢查（牆後敵人不再對著牆攻擊而卡死）與鎖死逃逸機制；敵人貼近時後撤／側閃更果斷
- **新敵人（v2.3）**：炸彈兵會點燃自爆（近距離範圍傷害，擊殺它也會爆炸）；旋轉哨兵以旋轉光束掃射，踏入光束會受傷
- **Boss 狂暴（v2.3）**：Boss 血量低於 10% 進入狂暴——加速、傷害提升、召喚間隔減半、短暫無敵
- **新天氣（v2.3）**：雪（白色緩落粒子、冷色薄霧）與沙塵暴（斜向塵粒、能見度大幅下降）

### 地圖編輯器

- 完整地圖編輯：畫牆、清除、填充、尖刺、鎖門、欄杆、起點／終點、筆刷大小與形狀
- 實體放置：敵人（巡邏者／追獵者／射手／坦克／群聚／分裂體／Boss／炸彈兵／哨兵）、道具（回復／加速／護盾／無敵／水晶／經驗石／體魄／揭露）、鑰匙、寶石、成對傳送點
- 工具：復原／重做（100 層）、複製／剪下／貼上、矩形／直線繪圖、框選刪除
- 驗證（v2.3）：統計列即時檢查可達性、鎖門與鑰匙數量、傳送點是否成對
- 範本：經典迷宮、競技場、螺旋塔、房間迷宮、尖刺走廊
- 存檔槽 ×3（v2.3 可改名、複製到其他槽）、圖層顯示切換、JSON 匯入／匯出、匯出 PNG 圖片、3D 預覽
- 儲存後即成為預設地圖，也可一鍵切回隨機迷宮

### 成就與統計

- 43 項成就（通關、收集、戰鬥、探索、連勝 5／10／20、彩蛋等），含進度條與稀有度
- 統計面板：遊玩時間、步數、寶石、擊殺、連勝、常用尺寸等
- 進度以 localStorage 保存於本機瀏覽器
- 無障礙（v2.3）：蹲下狀態指示燈、Toast 提示時長可調、螢幕特效（傷害紅暈／震動）獨立開關

## 操作方式

### 桌面

| 按鍵 | 動作 |
| --- | --- |
| W / A / S / D 或方向鍵 | 移動 |
| 滑鼠 | 轉向（點擊畫面鎖定滑鼠） |
| Shift | 奔跑 |
| Q 或雙擊 Shift | 衝刺 |
| 空白鍵 / 左鍵 | 攻擊 |
| E | 發射能量彈 |
| C | 蹲下（潛行） |
| F | 手電筒 |
| M | 小地圖 |
| G | 上帝視角 |
| P | 自動遊玩 |
| ESC | 暫停選單 |

### 移動端

- 左側虛擬搖桿移動、右側滑動轉向
- 螢幕按鈕：攻擊、衝刺、能量彈、奔跑、手電筒、地圖、自動、神（上帝視角）、暫停

## 隱藏內容

輸入 Konami 指令（↑ ↑ ↓ ↓ ← → ← → B A）可觸發隱藏彩蛋。

## 技術說明

- 純 HTML / CSS / JavaScript，單檔無外部資源
- Raycasting：DDA 射線步進、紋理對應、Sprite 排序渲染
- 音效：WebAudio 即時合成（腳步、攻擊、環境、雷聲等），無音訊檔
- 儲存：localStorage（設定、成就、統計、自訂地圖、存檔槽）
- 無障礙：字體大小、色盲模式、減少動效、高對比模式

## 開發備註

- 介面文案一律使用繁體中文。
