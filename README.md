# 光影迷宮（Raycasting 3D 迷宮）

單檔 HTML5 的第一人稱 3D 迷宮遊戲，使用偽 3D Raycasting 引擎渲染，無任何外部依賴，開啟瀏覽器即可遊玩。支援桌面（鍵盤滑鼠）與移動端（觸控搖桿）。

- 版本：v7.3
- 語言：繁體中文（zh-TW）
- 檔案：`raycast-maze.html`（單檔，約 16,817 行）

## 快速開始

直接用瀏覽器開啟 `raycast-maze.html` 即可，不需安裝或連網。

```
raycast-maze.html
```

或在本機啟動簡單伺服器後瀏覽（非必要，純本機檔案也可直接開啟）：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000/raycast-maze.html
```

## 遊戲內容

從綠色起點出發，避開陷阱與敵人，收集寶石與道具，找到金色終點即可通關。

### 核心系統

- **偽 3D 渲染**：自製 Raycasting 引擎、紋理貼圖、動態光照、手電筒、霧、晝夜循環、天氣（雨／暴風／霧／雪／沙塵暴／極光）
- **多尺寸迷宮**：15 檔隨機迷宮（迷你 7×7 ～ 永劫 129×129），遞迴回溯演算法生成，每局不同
- **難度**：普通／困難／噩夢（噩夢無小地圖、視野更短）
- **敵人**：巡邏者、追獵者、遠程射手、裝甲坦克、群聚 swarm、炸彈兵（自爆）、旋轉哨兵（光束）、分裂體、潛伏者 Lurker（半隱形突襲）、治療術士（治療友軍、被殺觸發全團沉默）、迴聲巫妖（召喚半透明分身）、地雷蟲（近距埋設尖刺）、盾槍兵（正面 70° 護盾格擋、需繞後或衝刺穿背）、相位幽靈（每 4-6 秒閃現追擊、半透明靛藍）、寶箱哥布林（逃竄寶藏目標、擊殺掉額外寶石）、四階段 Boss（含狂暴）
- **戰鬥**：近戰武器連擊、衝刺（v2.6 起可穿越敵人造成傷害）、能量彈、升級／經驗值／連擊倍率
- **道具**：補血、加速、護盾、無敵、能量水晶、經驗石、體魄（提升最大生命）、地圖卷軸；戰鬥道具——護盾（5 秒免疫）、手雷（前方引爆）、炮彈（地圖瞄準轟炸）、閃電卷軸（拾取即施放：半徑 5 格敵人 80 傷＋0.5 秒麻痺）、護符（受傷時自動消耗並無敵 2 秒）、冰霜手雷（半徑 3 格凍結 2 秒、Boss 免疫）、回溯捲軸（回到最後寶石檢查點）、透視藥水（拾取即生效：8 秒內小地圖標示未收集寶石位置）、煙霧彈（5 秒內敵人失去主動視線、接觸傷害仍可）、戰爭號角（8 秒內近戰與彈幕傷害 ×1.5、Boss 效果減半）
- **機關**：尖刺陷阱、鎖門（需鑰匙）、成對傳送點、寶石檢查點、冰面（滑行慣性）、崩落地板（碎裂前警告、緊急撤離、連鎖碎裂）、積水（減速地形、蹲下減半、無法衝刺）、加速地板（速度 ×1.55、敵人不受影響）
- **特殊事件**：血月——白天低機率降臨，期間敵人狂暴加速、通關可解「血月倖存者」；極光——綠色流光色帶＋偶發流星，純視覺不影響移動；隕石雨——落點預警圈後半徑 1 格範圍 25 傷（同時間最多 3 落點）；日蝕——20 秒藍紫濾鏡與環境光下降，純視覺。寶箱哥布林——白天隨機逃竄的金色目標，擊殺掉落額外寶石（可關閉）。豐收光環——白天隨機 15 秒的正面事件，經驗值 ×2（可關閉）。事件皆可在設定面板關閉
- **模式（開始畫面開關）**：計時挑戰——HUD 即時秒錶＋個人最佳比對，破紀錄顯示 NEW RECORD；一命模式——死亡即結算回主選單；每日迷宮——以當天日期為種子生成固定迷宮，當日所有人一致，記錄當日最佳，並追蹤連續打卡天數；無盡模式——跳過寶石與終點，每 15 秒一波敵人、波次越高越強，看你能撐幾波；寶石獵殺——90 秒限時計分，寶石分批重生、越收越快，挑戰單局高分；**潛入模式**——偷迷宮中央的寶物再原路逃出，敵人有視野、HUD 偵測度條滿了觸發全圖警報，被抓 3 次失敗；**塔防模式**——一端巢穴一端家，放三種防禦塔（火槍單體持續傷害／冰凍減速／砲塔範圍爆炸）擋住無限波次，家 HP 歸零失敗、清完第 20 波通關；**密室逃脫**——房間制，三種謎題（開關順序／壓板推箱／記憶密碼）解一道開一道門，通關最後房間出口獲勝；**獵殺模式**——角色互換主動追殺 3-5 隻精英獵物，殺夠數量才開出口
- **學習模式**：通關後與 A* 最短路徑對比，顯示繞路格數與效率
- **上帝視角（v2.2，v3.0 修正）**：按 `G`（或觸控「神」按鈕）切換 3D 俯視全圖——牆、門、尖刺、寶石、鑰匙、傳送點、終點、敵人、玩家朝向與自動遊玩規劃路徑一目了然，遊戲照常運行。全屏 3D＋滾輪／雙指縮放＋拖曳轉動視角＋返回按鈕；移動端上帝視角可直接用搖桿操控角色；牆體連續整體（背面剔除）；深度排序修正（旋轉視角不穿面）

### 自動遊玩與演算法

- 一鍵自動尋路通關，支援 **A\*／BFS／貪婪** 三種演算法切換
- 路徑對比模式：同時顯示三種演算法的路徑與距離
- 幽靈模式：顯示最短路徑的教學幽靈
- **AI 戰鬥（v2.2）**：自動遊玩遇到敵人會主動面向攻擊，敵人貼近時側向閃避／後退風箏，不再被動挨打或卡住
- **路線優化（v2.2）**：目標選擇會評估「到寶石 + 寶石到終點」的整體路徑長度，選總路線最短的寶石，避免先拿近但繞遠的寶石
- **卡住偵測重做（v2.8）**：以「淨位移累積窗口」判定卡住——牆角微震盪不再繞過偵測；同目標連續卡住 3 次自動放棄該寶石改攻他處（黑名單），根治自動遊玩原地慢爬／凍結
- **AI 收寶石修正（v3.1／v3.2）**：收集寶石階段把終點視為牆（`pfIgnoreEnd`），避免路徑穿過終點誤觸發通關；起點可達性 BFS 驗證（含傳送點通道、門算可走），不可達寶石直接丟棄；黑名單清空重試＋候選擴大搜尋，根治 AI 放棄寶石直衝終點
- **傳送點建模（v3.3）**：尋路演算法（A\*／BFS／DFS）展開時把傳送墊另一端視為可達，密室寶石現在會被 AI 收取
- **旗標防護（v3.3）**：`pfIgnoreEnd`／`pfAutoDoors` 改 try/finally 復位，任何異常路徑旗標必歸零
- **AI 門死鎖修復（v2.7）**：自動遊玩尋路視鎖門為可行走，前方被鎖門擋住時 AI 直接開門（無需鑰匙）
- **衝刺（v2.6）**：AI 在直線走廊 ≥3 格自動衝刺，衝完立即重算路徑避免折返

## 技術說明

- 純 HTML / CSS / JavaScript，單檔無外部資源
- Raycasting：DDA 射線步進、紋理對應、Sprite 排序渲染
- 音效：WebAudio 即時合成（腳步、攻擊、環境、雷聲等），無音訊檔；音樂／音效／環境三軌獨立音量
- 儲存：localStorage（設定、成就、統計、自訂地圖、存檔槽、每日最佳）
- 無障礙：字體大小、色盲模式（紅／綠／藍弱視四選一）、減少動效、高對比模式

## 開發備註

- 所有內容集中於單一 HTML 檔案，修改後直接重新整理即可生效。
- 新增成就請同時更新 `ACH_DEFS` 與解鎖條件，並確認無 emoji 圖示（成就使用文字／CSS 圖示）。
- 介面文案一律使用繁體中文。
- 新增 UI 元素請沿用 `:root` 設計 tokens，保持全站一致。
- 事件與模式等豐富內容一律提供設定開關，預設畫面保持簡潔。
