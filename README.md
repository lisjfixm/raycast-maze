# 光影迷宮（Raycasting 3D 迷宮）

單檔 HTML5 的第一人稱 3D 迷宮遊戲，使用偽 3D Raycasting 引擎渲染，無任何外部依賴，開啟瀏覽器即可遊玩。支援桌面（鍵盤滑鼠）與移動端（觸控搖桿）。

- 版本：v2.7
- 語言：繁體中文（zh-TW）
- 檔案：`raycast-maze.html`（單檔，約 12,100 行）

## 快速開始

直接用瀏覽器開啟 `raycast-maze.html` 即可，不需安裝或連網。

```
raycast-maze.html
```

或在本機啟動簡單伺服器後瀏覽（非必要，純本機檔案也可直接開啟）：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000/raycast-maze.html
```

## 遊戲內容

從綠色起點出發，避開陷阱與敵人，收集寶石與道具，找到金色終點即可通關。

### 核心系統

- **偽 3D 渲染**：自製 Raycasting 引擎、紋理貼圖、動態光照、手電筒、霧、晝夜循環、天氣（雨／暴風／霧／雪／沙塵暴／極光）
- **多尺寸迷宮**：13 檔隨機迷宮（迷你 5×5 ～ 無邊 89×89），遞迴回溯演算法生成，每局不同
- **難度**：普通／困難／噩夢（噩夢無小地圖、視野更短）
- **敵人**：巡邏者、追獵者、遠程射手、裝甲坦克、群聚 swarm、炸彈兵（自爆）、旋轉哨兵（光束）、分裂體、潛伏者 Lurker（半隱形突襲）、治療術士（治療友軍、被殺觸發全團沉默）、四階段 Boss（含狂暴）
- **戰鬥**：近戰武器連擊、衝刺、能量彈、升級／經驗值／連擊倍率
- **道具**：補血、加速、護盾、無敵、能量水晶、經驗石、體魄（提升最大生命）、地圖卷軸；戰鬥道具——護盾（5 秒免疫）、手雷（前方引爆）、炮彈（地圖瞄準轟炸）、閃電卷軸（拾取即施放：半徑 5 格敵人 80 傷＋0.5 秒麻痺）、護符（受傷時自動消耗並無敵 2 秒）
- **機關**：尖刺陷阱、鎖門（需鑰匙）、成對傳送點、寶石檢查點、冰面（滑行慣性）、崩落地板（碎裂前警告、緊急撤離）
- **特殊事件（v2.5）**：血月——白天低機率降臨，期間敵人狂暴加速、通關可解「血月倖存者」；極光——綠色流光色帶＋偶發流星，純視覺不影響移動
- **學習模式**：通關後與 A* 最短路徑對比，顯示繞路格數與效率
- **上帝視角（v2.2，v2.7 強化）**：按 `G`（或觸控「神」按鈕）切換 3D 俯視全圖——牆、門、尖刺、寶石、鑰匙、傳送點、終點、敵人、玩家朝向與自動遊玩規劃路徑一目了然，遊戲照常運行。v2.4 起全屏 3D＋滾輪／雙指縮放＋左右拖曳轉動視角＋返回按鈕（不再顯示平面小地圖）；v2.6 起移動端上帝視角可直接用搖桿操控角色；v2.7 牆體改連續整體（相鄰牆合併、背面剔除，不再一格一格分離）

### 自動遊玩與演算法

- 一鍵自動尋路通關，支援 **A\*／BFS／貪婪** 三種演算法切換
- 路徑對比模式：同時顯示三種演算法的路徑與距離
- 幽靈模式：顯示最短路徑的教學幽靈
- **AI 戰鬥（v2.2）**：自動遊玩遇到敵人會主動面向攻擊，敵人貼近時側向閃避／後退風箏，不再被動挨打或卡住
- **路線優化（v2.2）**：目標選擇會評估「到寶石 + 寶石到終點」的整體路徑長度，選總路線最短的寶石，避免先拿近但繞遠的寶石
- 修復（v2.2）：地圖尺寸與敵人數量可同時選擇，不再互相覆寫
- **戰鬥強化（v2.3）**：自動遊玩戰鬥加入視線檢查（牆後敵人不再對著牆攻擊而卡死）與鎖死逃逸機制；敵人貼近時後撤／側閃更果斷
- **新敵人（v2.3）**：炸彈兵會點燃自爆（近距離範圍傷害，擊殺它也會爆炸）；旋轉哨兵以旋轉光束掃射，踏入光束會受傷
- **Boss 狂暴（v2.3）**：Boss 血量低於 10% 進入狂暴——加速、傷害提升、召喚間隔減半、短暫無敵
- **新天氣（v2.3）**：雪（白色緩落粒子、冷色薄霧）與沙塵暴（斜向塵粒、能見度大幅下降）
- **分步教學（v2.4）**：首次進入遊戲依序引導「移動 → 攻擊 → 拾取寶石 → 開門」，每步完成才推進，可一鍵略過，不阻擋操作
- **音效分軌（v2.4）**：主音量拆為音樂／音效／環境三條獨立滑桿（預設 100%），雨聲走環境音、所有合成音效走音效軌
- **色盲模式擴充（v2.4）**：關閉／紅色弱視／綠色弱視／藍色弱視四選一，敵人類型與寶石依模式重新映射色盤；舊布林存檔自動相容
- **迷宮生成參數（v2.4）**：開始畫面可調環路率（無／普通／多）、走廊密度（單通道／多分支）、鏡射對稱開關，預設值等同舊行為
- **效能與修正（v2.4）**：BFS 尋路改指標式佇列、尋路 TypedArray 模組層重用、雨聲於死亡／回主選單正確停止、炮彈瞄準期間暫停敵人、無怪模式不再誤解「和平主義」成就
- **潛伏者（v2.5）**：新敵人 Lurker——平時近乎隱形，玩家接近才現身加速突襲，大地圖才入列
- **冰面／崩落地板（v2.5）**：冰面 tile 行走帶滑行慣性；崩落地板碎裂前先警告、玩家自動緊急撤離
- **血月／物件池（v2.5）**：血月隨機事件；投射物／粒子／繪製清單全面改預配置物件池，消除每幀 GC 壓力
- **平衡調整（v2.5）**：Boss HP 依迷宮面積與難度縮放（基礎 300 起，越大／越難越高）；swarm 每局最多生成一群
- **治療術士（v2.5）**：新敵人 healer——不主動攻擊，每 3 秒為範圍 4 內最弱友軍回 20 HP（綠色治療投射物）；被擊殺後全團沉默 5 秒（期間敵人不施放射擊／召喚／彈幕／治療等特殊技能）
- **新道具（v2.5）**：閃電卷軸（拾取即施放範圍麻痺電擊）、護符（受傷自動抵擋並無敵 2 秒，HUD 增益狀態顯示）
- **極光天氣（v2.5）**：天空綠色流光色帶＋偶發流星，純視覺不影響移動
- **筆刷與匯出（v2.5）**：編輯器筆刷大小擴充至 1–5（按鈕＋滑桿雙向同步）；JSON 下載檔名自動含地圖名稱
- **衝刺重做（v2.6）**：衝刺固定朝正前方衝 3 格、撞牆立即停止、5 秒冷卻（HUD 顯示倒數）；AI 自動遊玩在直線走廊 ≥3 格時自動衝刺，衝完立即重算路徑避免折返
- **AI 轉彎修復（v2.6）**：路徑轉彎點要求更貼近格中心（0.35），避免轉彎時撞牆角；卡住偵測縮短至 0.4 秒，觸發時先後退 0.12 格解卡再重規劃
- **AI 門死鎖修復（v2.7）**：自動遊玩尋路視鎖門為可行走，但物理碰撞把門當牆——現在前方被鎖門擋住時 AI 直接開門（無需鑰匙），徹底解決斜向接近門卡死的軟鎖；轉向角同時歸位（不再無限累加超出 ±π）

### 地圖編輯器

- 完整地圖編輯：畫牆、清除、填充、尖刺、鎖門、欄杆、起點／終點、筆刷大小（1–5，按鈕＋滑桿）與形狀（方／圓）
- 實體放置：敵人（巡邏者／追獵者／射手／坦克／群聚／分裂體／Boss／炸彈兵／哨兵／潛伏者／治療術士）、道具（回復／加速／護盾／無敵／水晶／經驗石／體魄／揭露／閃電卷軸／護符）、鑰匙、寶石、成對傳送點
- 工具：復原／重做（100 層）、複製／剪下／貼上、矩形／直線繪圖、框選刪除
- 驗證（v2.3）：統計列即時檢查可達性、鎖門與鑰匙數量、傳送點是否成對
- 範本：經典迷宮、競技場、螺旋塔、房間迷宮、尖刺走廊
- 存檔槽 ×3（可改名、複製到其他槽）、圖層顯示切換、JSON 匯入／匯出、JSON 下載（檔名自動含地圖名）、匯出 PNG 圖片、3D 預覽
- 儲存後即成為預設地圖，也可一鍵切回隨機迷宮

### 成就與統計

- 53 項成就（通關、收集、戰鬥、探索、連勝 5／10／20、彩蛋、冰面滑行、血月倖存、潛伏者獵殺、崩落逃生、零傷連勝、火炮齐鸣、連擊狂潮、徹夜破關、道具雜家、資深設計師等），含進度條與稀有度
- 統計面板：遊玩時間、步數、寶石、擊殺、連勝、常用尺寸等
- 進度以 localStorage 保存於本機瀏覽器
- 無障礙（v2.3）：蹲下狀態指示燈、Toast 提示時長可調、螢幕特效（傷害紅暈／震動）獨立開關

## 操作方式

### 桌面

| 按鍵 | 動作 |
| --- | --- |
| W / A / S / D 或方向鍵 | 移動 |
| 滑鼠 | 轉向（點擊畫面鎖定滑鼠） |
| Shift | 奔跑 |
| Q 或雙擊 Shift | 衝刺 |
| 空白鍵 / 左鍵 | 攻擊 |
| E | 發射能量彈 |
| C | 蹲下（潛行） |
| F | 手電筒 |
| M | 小地圖 |
| G | 上帝視角 |
| P | 自動遊玩 |
| ESC | 暫停選單 |

### 移動端

- 左側虛擬搖桿移動、右側滑動轉向
- 螢幕按鈕：攻擊、衝刺、能量彈、奔跑、手電筒、地圖、自動、神（上帝視角）、暫停

## 技術說明

- 純 HTML / CSS / JavaScript，單檔無外部資源
- Raycasting：DDA 射線步進、紋理對應、Sprite 排序渲染
- 音效：WebAudio 即時合成（腳步、攻擊、環境、雷聲等），無音訊檔
- 儲存：localStorage（設定、成就、統計、自訂地圖、存檔槽）
- 無障礙：字體大小、色盲模式（v2.4 起為紅／綠／藍弱視四選一）、減少動效、高對比模式

## 開發備註

- 所有內容集中於單一 HTML 檔案，修改後直接重新整理即可生效。
- 新增成就請同時更新 `ACH_DEFS` 與解鎖條件，並確認無 emoji 圖示（成就使用文字／CSS 圖示）。
- 介面文案一律使用繁體中文。
