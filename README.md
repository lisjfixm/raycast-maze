# 光影迷宮（Raycasting 3D 迷宮）

單檔 HTML5 的第一人稱 3D 迷宮遊戲，使用偽 3D Raycasting 引擎渲染，無任何外部依賴，開啟瀏覽器即可遊玩。支援桌面（鍵盤滑鼠）與移動端（觸控搖桿）。

- 版本：v3.0
- 語言：繁體中文（zh-TW）
- 檔案：`raycast-maze.html`（單檔，約 13,150 行）

## 快速開始

直接用瀏覽器開啟 `raycast-maze.html` 即可，不需安裝或連網。

```
raycast-maze.html
```

或在本機啟動簡單伺服器後瀏覽（非必要，純本機檔案也可直接開啟）：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000/raycast-maze.html
```

## 遊戲內容

從綠色起點出發，避開陷阱與敵人，收集寶石與道具，找到金色終點即可通關。

### 核心系統

- **偽 3D 渲染**：自製 Raycasting 引擎、紋理貼圖、動態光照、手電筒、霧、晝夜循環、天氣（雨／暴風／霧／雪／沙塵暴／極光）
- **多尺寸迷宮**：13 檔隨機迷宮（迷你 5×5 ～ 無邊 89×89），遞迴回溯演算法生成，每局不同
- **難度**：普通／困難／噩夢（噩夢無小地圖、視野更短）
- **敵人**：巡邏者、追獵者、遠程射手、裝甲坦克、群聚 swarm、炸彈兵（自爆）、旋轉哨兵（光束）、分裂體、潛伏者 Lurker（半隱形突襲）、治療術士（治療友軍、被殺觸發全團沉默）、迴聲巫妖（召喚半透明分身）、地雷蟲（近距埋設尖刺）、四階段 Boss（含狂暴）
- **戰鬥**：近戰武器連擊、衝刺（v2.6 起可穿越敵人造成傷害）、能量彈、升級／經驗值／連擊倍率
- **道具**：補血、加速、護盾、無敵、能量水晶、經驗石、體魄（提升最大生命）、地圖卷軸；戰鬥道具——護盾（5 秒免疫）、手雷（前方引爆）、炮彈（地圖瞄準轟炸）、閃電卷軸（拾取即施放：半徑 5 格敵人 80 傷＋0.5 秒麻痺）、護符（受傷時自動消耗並無敵 2 秒）、冰霜手雷（半徑 3 格凍結 2 秒、Boss 免疫）、回溯捲軸（回到最後寶石檢查點）
- **機關**：尖刺陷阱、鎖門（需鑰匙）、成對傳送點、寶石檢查點、冰面（滑行慣性）、崩落地板（碎裂前警告、緊急撤離、連鎖碎裂）
- **特殊事件**：血月——白天低機率降臨，期間敵人狂暴加速、通關可解「血月倖存者」；極光——綠色流光色帶＋偶發流星，純視覺不影響移動；隕石雨——落點預警圈後半徑 1 格範圍 25 傷（同時間最多 3 落點）；日蝕——20 秒藍紫濾鏡與環境光下降，純視覺。事件皆可在設定面板關閉
- **模式（開始畫面開關）**：計時挑戰——HUD 即時秒錶＋個人最佳比對，破紀錄顯示 NEW RECORD；一命模式——死亡即結算回主選單；每日迷宮——以當天日期為種子生成固定迷宮，當日所有人一致，記錄當日最佳
- **學習模式**：通關後與 A* 最短路徑對比，顯示繞路格數與效率
- **上帝視角（v2.2，v3.0 修正）**：按 `G`（或觸控「神」按鈕）切換 3D 俯視全圖——牆、門、尖刺、寶石、鑰匙、傳送點、終點、敵人、玩家朝向與自動遊玩規劃路徑一目了然，遊戲照常運行。全屏 3D＋滾輪／雙指縮放＋拖曳轉動視角＋返回按鈕；移動端上帝視角可直接用搖桿操控角色；牆體連續整體（背面剔除）；深度排序修正（旋轉視角不穿面）

### UI／UX（v3.0）

- **設計系統**：全域設計 tokens（色盤、字級階梯、間距、圓角、按鈕／滑桿／下拉／輸入框統一風格、焦點環），全站面板與 HUD 套用，桌面與移動端一致
- **HUD 不擋視野**：狀態列靠邊緣、半透明、互不重疊（移動端修正 hp 欄與中央欄重疊）；連擊／浮動文字節流（同時最多 4 條）
- **設定面板分組**：顯示／音效／操控／無障礙／內容與模式五組，每組標題清晰，預設全展開
- **成就面板篩選**：全部／已解鎖／未解鎖三態過濾
- **畫面克制**：預設狀態簡潔；事件與模式皆有開關，豐富內容集中在設定與解鎖後

### 自動遊玩與演算法

- 一鍵自動尋路通關，支援 **A\*／BFS／貪婪** 三種演算法切換
- 路徑對比模式：同時顯示三種演算法的路徑與距離
- 幽靈模式：顯示最短路徑的教學幽靈
- **AI 戰鬥（v2.2）**：自動遊玩遇到敵人會主動面向攻擊，敵人貼近時側向閃避／後退風箏，不再被動挨打或卡住
- **路線優化（v2.2）**：目標選擇會評估「到寶石 + 寶石到終點」的整體路徑長度，選總路線最短的寶石，避免先拿近但繞遠的寶石
- **卡住偵測重做（v2.8）**：以「淨位移累積窗口」判定卡住——牆角微震盪不再繞過偵測；同目標連續卡住 3 次自動放棄該寶石改攻他處（黑名單），根治自動遊玩原地慢爬／凍結
- **AI 門死鎖修復（v2.7）**：自動遊玩尋路視鎖門為可行走，前方被鎖門擋住時 AI 直接開門（無需鑰匙）
- **衝刺（v2.6）**：AI 在直線走廊 ≥3 格自動衝刺，衝完立即重算路徑避免折返

### 地圖編輯器

- 完整地圖編輯：畫牆（含石牆、金屬板）、清除、填充、尖刺、鎖門、欄杆、冰面、崩落地板、起點／終點、筆刷大小（1–5，按鈕＋滑桿）與形狀（方／圓）
- 實體放置：全部敵人（巡邏者／追獵者／射手／坦克／群聚／分裂體／Boss／炸彈兵／哨兵／潛伏者／治療術士／迴聲巫妖／地雷蟲）、道具（回復／加速／護盾／無敵／水晶／經驗石／體魄／揭露／閃電卷軸／護符／冰霜手雷／回溯捲軸）、鑰匙、寶石、成對傳送點
- 工具：復原／重做（100 層）、複製／剪下／貼上（保護起終格）、矩形／直線繪圖、框選刪除、拖動實體可復原
- 驗證（v2.3）：統計列即時檢查可達性、鎖門與鑰匙數量、傳送點是否成對；起點／終點不可在牆或崩落地板上
- 範本：經典迷宮、競技場、螺旋塔、房間迷宮、尖刺走廊
- 存檔槽 ×3（可改名、複製到其他槽；覆寫前有確認）、圖層顯示切換、JSON 匯入／匯出（支援全部 tile 型別含冰面／崩落）、JSON 下載（檔名自動含地圖名）、匯出 PNG 圖片（與編輯器所見一致，檔名含地圖名）、3D 預覽
- 儲存後即成為預設地圖，也可一鍵切回隨機迷宮
- 設定／成就存檔做型別與範圍驗證（壞資料自動回預設）

### 成就與統計

- 66 項成就（通關、收集、戰鬥、探索、連勝 5／10／20、彩蛋、冰面滑行、血月倖存、潛伏者獵殺、崩落逃生、零傷連勝、火炮齐鸣、連擊狂潮、徹夜破關、道具雜家、資深設計師、衝刺刺客、幻影獵手、分身粉碎者、除蟲大師、冰封大師、絕處逢生、隕石舞者、日蝕觀測者、破紀錄者、時空獵手、一命大師、每日勇士、每日達人等），含進度條與稀有度、全部／已解鎖／未解鎖篩選
- 統計面板：遊玩時間、步數、寶石、擊殺、連勝、常用尺寸等
- 進度以 localStorage 保存於本機瀏覽器
- 無障礙（v2.3）：蹲下狀態指示燈、Toast 提示時長可調、螢幕特效（傷害紅暈／震動）獨立開關

## 操作方式

### 桌面

| 按鍵 | 動作 |
| --- | --- |
| W / A / S / D 或方向鍵 | 移動 |
| 滑鼠 | 轉向（點擊畫面鎖定滑鼠） |
| Shift | 奔跑 |
| Q 或雙擊 Shift | 衝刺 |
| 空白鍵 / 左鍵 | 攻擊 |
| E | 發射能量彈 |
| C | 蹲下（潛行） |
| F | 手電筒 |
| M | 小地圖 |
| G | 上帝視角 |
| P | 自動遊玩 |
| 1 / 2 / 3 / 4 / 5 | 道具（護盾／手雷／炮彈／冰霜手雷／回溯捲軸） |
| ESC | 暫停選單 |

### 移動端

- 左側虛擬搖桿移動、右側滑動轉向
- 螢幕按鈕：攻擊、衝刺、能量彈、奔跑、手電筒、地圖、自動、神（上帝視角）、暫停、道具

## 技術說明

- 純 HTML / CSS / JavaScript，單檔無外部資源
- Raycasting：DDA 射線步進、紋理對應、Sprite 排序渲染
- 音效：WebAudio 即時合成（腳步、攻擊、環境、雷聲等），無音訊檔；音樂／音效／環境三軌獨立音量
- 儲存：localStorage（設定、成就、統計、自訂地圖、存檔槽、每日最佳）
- 無障礙：字體大小、色盲模式（紅／綠／藍弱視四選一）、減少動效、高對比模式

## 開發備註

- 所有內容集中於單一 HTML 檔案，修改後直接重新整理即可生效。
- 新增成就請同時更新 `ACH_DEFS` 與解鎖條件，並確認無 emoji 圖示（成就使用文字／CSS 圖示）。
- 介面文案一律使用繁體中文。
- 新增 UI 元素請沿用 `:root` 設計 tokens，保持全站一致。
- 事件與模式等豐富內容一律提供設定開關，預設畫面保持簡潔。
